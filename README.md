# LEARNING PROJECT: MNIST training via backpropagation in Mojo

This project will contain a simple MNIST digit recognizer using AdamW. This is a port of an earlier pure-Rust, CPU-only version I wrote. This version will use Mojo and MAX and run on a GPU.

## Contributing

This is a learning project, so there's no real need for contributions. But if you _do_ explore it and find a bug, then a PR is welcome.

## AI Policy

Because this is a learning project, no AI code will be accepted or used. (Doing so rather defeats the purpose.) There _are_ an AGENTS.md and skill files so that an open-weight model can look things up for me and answer questions. Non-code AI output:

- [MNIST_REIMPLEMENTATION_NOTES.md](docs/MNIST_REIMPLEMENTATION_NOTES.md) is an AI-written summary of the original Rust implementation courtesy of DeepSeek V4 Flash 0731, so I don't need to compute all the derivates from scratch again.
