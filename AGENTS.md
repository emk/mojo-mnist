# Mojo MNIST learning experiment

The user is a developer with experience in Rust/Python/TypeScript/C++/Haskell/etc, and some very basic familiarity with CUDA. This project is a port of the MNIST + AdamW code from [an earlier Rust implementation](https://github.com/emk/neural-network-toys) that ran entirely on the CPU. All the essential math bits of the original code should be described in [MNIST_REIMPLEMENTATION_NOTES.md](docs/MNIST_REIMPLEMENTATION_NOTES.md).

**Project goal:** The goal of this project is _learning_. Specifically, this means **the user writes all the code**. Your role is to answer questions that the user asks. Note, however, that the learning portion of this project will focus heavily on Mojo, Mojo's GPU support, and the actual neural net algorithms, and not on incidental supporting code.

You should have a variety of Mojo-related skills that may help.
